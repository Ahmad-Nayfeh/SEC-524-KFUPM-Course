03Background you need: OT, PLC, Modbusخلفية لازمة: OT و PLC و Modbus

The topic chosen is Operational Technology (OT): the computers that run physical equipment in factories, power plants and substations. The normal office IT world protects data. OT protects machines and people.

الموضوع المختار هو التقنيات التشغيلية (OT): الأجهزة التي تشغّل المعدات الفعلية في المصانع ومحطات الكهرباء. عالم تقنية المعلومات العادي يحمي البيانات، أما OT فيحمي الآلات والناس.

PLC

A small industrial computer that controls a machine. It keeps settings in numbered memory slots called registers.

حاسب صناعي صغير يتحكم بآلة. يحفظ الإعدادات في خانات ذاكرة مرقّمة اسمها registers (سجلات).

Register 16

السجل رقم 16

In this project, one register is a setpoint (a target value, like a thermostat temperature). It starts at 50.

في المشروع، هذا السجل يمثل قيمة ضبط (setpoint)، مثل درجة الحرارة في المكيّف. قيمته الأصلية 50.

Modbus/TCP

The "language" engineers' computers use to talk to PLCs over a network. It has no passwords: anyone on the network can send commands.

"اللغة" التي يستخدمها حاسب المهندس للتحدث مع الـ PLC عبر الشبكة. لا يوجد فيها كلمة مرور: أي جهاز على الشبكة يستطيع إرسال أوامر.

Modbus commandأمر ModbusCodeالرقمMeaningالمعنى
Read Holding Registersقراءة السجلاتFC 03"What is the value now?" Safe, changes nothing."كم القيمة الآن؟" آمن ولا يغيّر شيئاً.
Write Single Registerكتابة سجل واحدFC 06"Set the value to X." This is the dangerous one. The PLC confirms by echoing the same message back."اجعل القيمة X". هذا الأمر الخطير. الـ PLC يؤكد التنفيذ بإرجاع نفس الرسالة.

04The story: the "crime" being investigatedالقصة: "الجريمة" محل التحقيق

Someone changed register 16 from 50 to 90. There was no approved change request for that period. The investigator must answer:

شخص ما غيّر السجل 16 من 50 إلى 90، ولا يوجد أي طلب تغيير معتمد في ذلك الوقت. على المحقق أن يجيب:

Investigative question: Can we prove what command was sent, from which machine, at what time, whether the PLC accepted it, and what we cannot prove (for example, which human pressed the key)?

سؤال التحقيق: هل نستطيع إثبات أي أمر أُرسل، ومن أي جهاز، وفي أي وقت، وهل قبله الـ PLC؟ وما الذي لا نستطيع إثباته (مثلاً: أي إنسان ضغط الزر)؟

Analogy: a factory door was opened at night. The camera footage shows the door opening. The guard's logbook says "door opened at 2:00". Both agree, so you trust it. But neither tells you whose hand opened it.

تشبيه: باب في المصنع فُتح ليلاً. كاميرا المراقبة تُظهر فتح الباب، ودفتر الحارس مكتوب فيه "فُتح الباب الساعة 2:00". الاثنان متفقان فنثق بالقصة. لكن لا أحد منهما يخبرك يد من فتحت الباب.

08What the evidence proves (I re-checked it myself)ماذا تثبت الأدلة (راجعتها بنفسي)

Here is the actual write command, packet 14 in incident.pcap, byte by byte. Every Modbus message has a 7-byte header (the "envelope") and then the command itself.

هذا هو أمر الكتابة الفعلي، الحزمة رقم 14 في incident.pcap، بايت ببايت. كل رسالة Modbus فيها رأس من 7 بايت ("الظرف") ثم الأمر نفسه.

00 01transaction ID = 1رقم العملية = 1
00 00protocol = Modbusالبروتوكول = Modbus
00 066 bytes followيتبعها 6 بايت
01unit ID = 1رقم الجهاز = 1
06FC 06 = WRITEFC 06 = كتابة
00 10register 0x10 = 16السجل 0x10 = 16
00 5Avalue 0x5A = 90القيمة 0x5A = 90

Then three independent checks point at the same event. In forensics this agreement is called corroboration, and it is what turns a guess into a finding.

ثم ثلاثة فحوصات مستقلة تشير لنفس الحدث. في الأدلة الجنائية هذا الاتفاق اسمه التعزيز (corroboration)، وهو ما يحوّل التخمين إلى نتيجة مثبتة.

09Fact, inference, unknownحقيقة، استنتاج، مجهول

The brief grades you on keeping these three apart. This is the most "detective-like" part of the report.

ملف المتطلبات يعطي درجات على الفصل بين هذه الثلاثة. هذا أكثر جزء "تحقيقي" في التقرير.

Observed facts

حقائق مُشاهَدة

  • A write FC06, reg 16, value 90 was sent from 10.20.30.20.
  • The PLC echoed it back (accepted).
  • The PLC log recorded 50 → 90.
  • A later read returned 90.
  • أُرسل أمر كتابة FC06 للسجل 16 بالقيمة 90 من 10.20.30.20.
  • الـ PLC أرجع نفس الرسالة (قَبِل).
  • سجل الـ PLC دوّن 50 ← 90.
  • قراءة لاحقة أعطت 90.

Reasonable inferences

استنتاجات معقولة

  • The change was unauthorized, but only because the scenario says no change request existed.
  • The command came from the OT-CLIENT VM, since it owned that IP.
  • التغيير غير مصرّح به، فقط لأن السيناريو يقول لا يوجد طلب تغيير.
  • الأمر جاء من جهاز OT-CLIENT لأنه صاحب هذا العنوان.

Unknowns

أمور مجهولة

  • Which human typed the command. Modbus has no user login.
  • Whether an IP could have been spoofed.
  • Any physical effect. There is no real machine.
  • أي إنسان كتب الأمر. Modbus لا يوجد فيه تسجيل دخول.
  • هل يمكن أن يكون العنوان مزوّراً.
  • أي أثر فيزيائي، فلا توجد آلة حقيقية.
